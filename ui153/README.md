# Подготовка настроек 153

Рабочие исходники следующей версии поверх опубликованной 152.
APK153 и финальный SOURCE153 пока не создавались; установленные приложения
этими файлами не изменены. Опубликованные 152/151 остаются неизменными.

В «Дополнительно» добавлены разделы Wave, T9 и «Общие настройки», разделители,
согласованные значки и подписи не длиннее двух строк. Общие пункты следуют
порядку владельца; «Автом. заглавные буквы» стоят после шести пронумерованных.
Выбор следующего слова пробелом недоступен при выключенном контекстном
прогнозировании; сохранённая галочка не сбрасывается. Используются прежние
объекты Preference, их значения и обработчики. Отдельный переключатель
подсказок в пустом поле не добавлен.

«Включить TouchPal» наблюдает изменения выбранного и разрешённых методов
ввода Android. Уже показанные заголовки сразу обновляют цвет; наблюдение
снимается при отсоединении окна. Переиспользованная строка другого пункта
не получает цвет TouchPal.

Проверки из корня репозитория:

```sh
python ui153/tests/run_api16.py
python ui153/tests/framework/run.py
```

Нужны JDK21, `tools/android-api16.jar`, Maven и зависимости Robolectric4.16.1.
Проверки интерфейса используют Android34/Robolectric, реальные Preference,
View и ContentResolver, а для границ закрытого приложения — явно обозначенные
тестовые двойники. APK152 служит только источником прежних значков.
Результаты — `SOURCE_API16.json`, `HOST_TESTS.json`; снимок строк —
`research/framework-capture/additional153-dark.png`.
Это не запуск закрытой клавиатуры на Android ART или телефоне.
