gTouchPal155 · основа TouchPal Keyboard6.2.7.1

Рецепт: BUILD_155.txt. Пользовательские изменения: CHANGELOG.md.
Финальные проверки: VERIFICATION.json. Это не AndroidART и не телефонная приёмка.
Начальную папку системного выбора, разрешение записи на SD, Sharesheet и реальный
нативный импорт необходимо проверить на устройстве.

Копии ZIP/USR и TXT — основное внешнее хранилище/TouchPalG/Backup.
Сохранение/восстановление позволяет выбрать другой файл или папку.
«Создать и отправить» сначала сохраняет обычный проверенный файл в стандартную
папку, затем отправляет этот же файл существующим FileProvider. Никакое событие
отмены/возврата/закрытия не удаляет сохранённую копию. Имена не перезаписываются.
Только приватные подготовленные файлы удаляются после копирования/отмены.

Raw western.usr — полный бинарный снимок; он не содержит отдельных настроек,
других файлов словаря и ручных правил WOR1. Эти данные переносит полный ZIP.
TXT экспортирует слова текущего проверенного снимка USR прежним UsrFileParser.
TXT импорт: UTF-8, один токен на строку, прежняя case-insensitive дедупликация,
подтверждение, append-only native API и проверенная копия до импорта. При сбое
предлагается оставить текущий результат или восстановить состояние до импорта.

BackupController, native release/init, WesternExport135, WesternImport137,
UsrFileParser, проверки/откат и StorageRoot135 унаследованы153 без изменения
байткода. Четыре ограниченных изменения в старых мод-экранах TXT — только UI
и каталог экспорта. Новые native-вызовы разрешены по фактическому DEX ABI.
Framework тесты используют реальный Android UI и файловый IO; closed-native,
USR-format validator и URI mapping представлены явно обозначенными двойниками.
