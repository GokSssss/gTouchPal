## Русский

- «Тема клавиатуры» открывает список установленных оформлений с отмеченной текущей темой.
- Разметка «Дополнительно» готовится перед показом; при возврате в настройки запрашивается скрытие клавиатуры.
- В резервном меню общая плашка «Сохранить» со значками папки и отправки. Папка открывает копии, отправка сохраняет файл и открывает «Поделиться».
- Кнопки, пояснения и отступы резервного меню стали компактнее.

Установка поверх 155 без удаления данных. Проверка этих переходов на телефоне ещё требуется.

## English

- Keyboard themes open as a list of installed styles with the current theme marked.
- Additional settings are arranged before display; returning to settings requests that the keyboard remain hidden.
- Backup actions share one strip: Save, open the backup folder, and save and share through Android.
- Backup buttons, descriptions and spacing are more compact.

Install over 155 without deleting data. These transitions still need phone verification.
