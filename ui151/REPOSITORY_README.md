# gTouchPal

Развитие TouchPal Deluxe и идейное продолжение модификации Tanh на основе TouchPal Keyboard6.2.7.1. Дальнейшая работа — GokS.

Выпуск151 выравнивает пункты настроек и меняет линию Wave-ввода на жёлтую#F6D333. Диагностика остаётся на долгом нажатии журнала; короткое открывает журнал.

[Скачать APK151](https://github.com/GokSssss/gTouchPal-/releases/download/v151/151-gTouchPal-6.2.7.1.apk) · [Все файлы выпуска](https://github.com/GokSssss/gTouchPal-/releases/tag/v151)

Установка поверх150 без удаления приложения и данных. Для Obtainium включите предварительные выпуски.

## Проверки

19тестов AndroidFramework/RobolectricSDK34, готовыйDEX/API16, сравнение10176прежних классов, прежний сертификатv1/v2/v3. Исходные обработчики диагностики, закрытый движок и данные сохранены. Это предварительный выпуск: телефон/реальныйIME151 ещё требует проверки. Возможный частичный сброс ручного порядка слов отдельно не воспроизведён.

## Сборка

[BUILD_151.txt](BUILD_151.txt), код модификаций в [ui151](ui151). Нужен точныйAPK150 из инструкции. SOURCE содержит наши изменения, а не полные исходники CooTek. Ключ и параметры остаются в обычной папке GoogleДиска, вGit/SOURCE/APK не включаются.
